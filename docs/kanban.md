# Kanban 交活

五个执行 profile 只通过 Kanban 收活。Sekhmet 是唯一派工人。

## 卡

- 标题写动作和靶标 ID，不写利用步骤。
- 正文只写目标、允许范围、完成标准、证据应写入的相对路径。
- 一张卡只有一个 assignee。
- 执行角色不互相派活，不向用户开新战线。

## 完成

- 完成说明只写：写入了哪一页、哪条索引、证据相对路径。
- 不写凭据真值、payload、命令细节。
- 未写入 Wiki 或 index.db 的卡，不算完成。

## 拒绝

- 授权页为空：拒绝主动动作。
- 同靶标已有 3 个未释放占用：拒绝新的写入卡。
- 高风险动作先停，等 Sekhmet 问过用户。
