4. 测试：新增 `tests/test_dashboard_api_m2.py`，用 `fastapi.testclient.TestClient`

## 端点

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/engagements` | 全部靶标（含显示名、创建时间，按创建时间倒序） |
| GET | `/engagements/current` | 旧兼容：仅 id 列表 |
| GET | `/engagements/for-session/{session_id}` | 按 `session.json` 反查绑定靶标 |
| GET | `/summary/{engagement_id}` | 态势汇总（计数、阶段、得分点） |
| GET | `/credentials/{engagement_id}` | 凭据指针 |
| GET | `/assets/{id}` `/findings/{id}` `/sessions/{id}` `/tunnels/{id}` `/report/{id}` `/skills` `/roles` | 保持不变 |

`summary` 中 `stage` 的推导顺序：`internal`（有隧道）→ `exploit`（有凭据或访问）→
`vuln`（有漏洞）→ `asset`（有资产）→ `recon`（空靶标）。`score` 与 `score_hits`
来自 `score_event` 的去重 `rule_id`。`services` 统计地址以 `http` 开头的资产。

## 风险 / 未竟事项

- 面板未在真实桌面窗口里点验（本任务只要求 ESM 解析 + 全量测试）。实时 UI 走查、
  与 `default` 会话的绑定/回退表现，留到 M3 的端到端验证。
- `导出` 按钮通过 `captureGatewayFileDownload()` 下载 `report-index.md`；若桌面
  连接的是远程后端，该文件路径只对网关主机有效，行为与 Hermes 的文件下载桥一致。
- `services` 目前以 `address LIKE 'http%'` 近似“Web 服务”，因为没有独立的
  service/port 表；若后续建表再改口径。
- `dashboard/manifest.json` 的 `tabs` 字段是 web-dashboard 遗留元数据（当前发现逻辑
  只读 `tab`/`slots`/`api`），改成五分区仅为消除陈旧引用，不影响桌面 pane。
